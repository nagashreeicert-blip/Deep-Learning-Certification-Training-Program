# 📘 Deep Learning Exam Pattern

This guide provides a clear overview of the Deep Learning certification exam structure to help you prepare effectively.

# ✅ 1. Total Questions

100–120 questions (varies by certification body)

All questions are scored

# ✅ 2. Question Types

Multiple Choice Questions (MCQs)

Scenario-based / case-study questions

Coding-based questions (Python, TensorFlow, PyTorch)

Mathematical/analytical problem-solving questions

Some questions may require selecting multiple correct answers

# ✅ 3. Exam Duration

120–180 minutes depending on the certification

No scheduled breaks for online proctored exams

# ✅ 4. Exam Format

The Deep Learning exam is a Computer-Based Exam (CBE).
You can take it via:

Online (Proctored)

Authorized Testing Centers

# ✅ 5. Domain-wise Weightage
Domain	Weight
Neural Network Basics	20%
Deep Learning Algorithms	30%
Model Training & Optimization	25%
Computer Vision / NLP (depending on track)	15%
Deployment & Real-World Applications	10%

Weightage may vary by certification provider (e.g., TensorFlow Developer Certificate, DeepLearning.AI Specializations, iCert Global Deep Learning Certification).

# ✅ 6. Difficulty Level

Moderate to high difficulty

Heavy emphasis on:

Understanding neural network concepts

Hyperparameter tuning

Real-world application scenarios

Python coding and framework knowledge

# ✅ 7. Passing Score

Passing criteria vary by exam provider

Recommended target:
# ➡️ 70–80% accuracy for safe performance

# ✅ 8. Exam Retake Policy

Depends on the certification:

Most providers allow 2–3 retakes per year

Mandatory cooling-off period may apply (e.g., 14 days)
